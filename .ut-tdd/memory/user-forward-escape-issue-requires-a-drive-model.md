PO rule 2026-07-14: Filing a GitHub Issue for a Forward escape requires an explicit drive_model selection. The filing contract must also bind origin PLAN Asset/revision/L/Forward state, escape reason, and re-entry policy. Unknown or inconsistent drive_model vs Issue/PLAN kind/branch kind fails closed. The selected drive model determines the PLAN template, V-pair obligations, schedule branch, workflow, and mandatory CI profile. Persist selection and any human override as evidence so escape counts by drive model/L/cause improve upstream Forward assumptions and design decisions.
