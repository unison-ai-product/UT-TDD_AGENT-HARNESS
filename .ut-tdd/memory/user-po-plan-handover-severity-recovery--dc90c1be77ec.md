PO対話に関する複数の確立ルール。チャット報連相は日本語で行う。「改善する」という指示は実装することを意味する(調査・提案止まりではない)。PLAN完了時はhandoverが必須である。強制停止(作業の即時中断を要する事態)は最高severityとして扱う。工程は記録のために必ず通す(近道で省略しない)。Recoveryは本線扱いであり、傍流の後回し作業として扱わない。
