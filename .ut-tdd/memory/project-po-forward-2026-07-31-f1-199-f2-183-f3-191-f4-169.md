### F1 = issue #199 — pair-mapping の substance 検査欠落 (fail-open 1/17)

- 内容: L8 freeze 属性表の属性セルが `&#34;` (entity decode で `"` になる記号 1 文字) だと
  doctor `resource-kernel-pair-mapping` が green のまま通る。`isBlankMarkdownCell`
  (`src/lint/resource-kernel-pair-mapping.ts:127`) が decode + tag 除去後に長さ 0 判定しかせず、
  記号 1 文字が「非空」として残るため。
- 対策方針 (issue #199 本文で確定済み): decode + tag 除去後の visible 文字列に
  **英数字・仮名・漢字が 1 文字も無ければ空扱い**。文字数下限のハードコード (8 文字) は
  doc 表記の正当な短縮を殺すので採らない。
- close 条件: 負 test に `&#34;` / `&#39;` / `.` / `-` / `?` の単独セルを含め、doctor 配線経路で
  fail-close することを実測 green で示す。**prose の完了宣言は受けない**。
- R2 (#197) の直接残債であり、対策方針が確定済み・小粒・close 条件が機械的なので先頭に置く。
