PO rule 2026-07-14: An Issue created outside the normal Forward path is not merely a defect ticket. It is a typed Forward-escape observation. Capture escape type (preemptive work, PoC, Reverse, Recovery, Incident, block, reject, supersede, defer), originating L/stage, assumption or decision under test, reason, original PLAN Asset/revision/state, re-entry target, evidence, and recurrence identity. Aggregate escape frequency by L/type/cause to improve Forward assumptions, upstream design decisions, evidence policy, and workflow. Optimize for reducing repeated same-cause escapes, not merely reducing Issue count. PoC S4 decision and re-entry/route outcome must close the learning loop.
