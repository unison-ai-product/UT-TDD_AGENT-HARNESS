北極星は spec 駆動 (SDD)。TDD/DDD は手段。基準は spec (SSoT) であって観測ではない。観測鵜呑み = fail-open の看板替え = 禁止。CI green は spec 遵守の帰結にすぎない。coverage は substance を保証しない (2026-06-08 核心教訓)。falsifiable な claim は必ず実 test/command で裏取りし、prose で断言しない (coding != substance)。
