# UT-TDD 構想書 v4.0 L3 要件候補 (チーム開発版)

## Authority 境界

本書は PLAN-L1-09 の未承認候補であり、current requirements (要件定義書 v1.2、VUP-REQ-01〜10)、Requirement IR、
runtime、DB へ投影しない。承認後は VUP-REQ-11〜 として `vmodel-engine-swap-requirements-delta.md` と同じ
