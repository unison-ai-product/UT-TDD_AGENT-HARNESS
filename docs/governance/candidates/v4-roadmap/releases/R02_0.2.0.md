# R02 / 0.2.0：運用基盤stable・安全な更新/切戻し

状態：版割当の提案・未実装/未受入。元M：M1＋並行運用系列。構想target：v4.0。
責任：release owner / distribution責務owner。実名/代理/予算上限は正式採択時に設定。
関連移行：MIG-05, MIG-15。

## 1. 利用者がこの版で得るもの
v4全機能を待たず、導入したPackを安全に更新・復旧できるstable基盤を作る。

## 2. 新しく対応する範囲
- #481: channel候補解決→sealed plan/dry-run→人間承認→隔離取得→原子的generation切替。
- state compatibility判定、doctor/smoke失敗時rollback、中断resume、append-only履歴。
- #364: Product A/Bの異version/channel、片系upgrade/rollback、障害非伝播の完全受入。
- 受入用途を阻害するreview保存/terminal/通知の既知欠陥を、既存issue責務で是正。

## 3. この版に入れないもの
- 差分binary配信、無承認のbackground更新、consumerソースの自動変更。
- 全v4機能の先行完成、別のupdater正本/配布サービス。

## 4. 何を入れ替え、何を残すか
| 旧方式 | 新方式 | 維持/境界 |
|---|---|---|
| tag最大値の更新案内中心 | channel/manifest/receiptに基づくupdate planとapply | 既存advisoryは互換入口として共通resolverへ委譲 |
| 手動置換と回復 | generation switchと検証済み切戻し | consumer stateをruntimeと分離 |

## 5. 着手と公開の条件
開発前提：R01。公開前提：R01。
開発前提の成立と、consumerへ新capabilityを有効化できる条件は別。必要な先行schema/安全性だけを早期sliceにし、未受入のwriteを先に許可しない。

| SL | 出力 | 検証 | 先行SL |
|---|---|---|---|
| SL-R02-01 候補解決と承認 | #481 resolver/plan/approval slice | malformed/無承認でwrite 0 | 版前提 |
| SL-R02-02 取得・切替・回復 | staging/digest/Windows lock/migration gate | 各phase fault injection | SL-R02-01 |
| SL-R02-03 A/B system受入 | 異版・片系故障・再開・auditor | 両OSと非著者closing | SL-R02-02 |

## 6. 受入と次版への昇格条件
| AC ID | 必要な証明 | 現状 |
|---|---|---|
| REL-R02-AC-01 | 破損manifest/receipt/digestや不適合stateでruntime/stateとも不変。 | 未実行 |
| REL-R02-AC-02 | Windows/Linuxでswitch中断後に旧世代または新世代の整合状態へ回復できる。 | 未実行 |
| REL-R02-AC-03 | Aの更新・review待ち・rollback失敗がBを停止/汚染しない。 | 未実行 |

各ACは下流PLAN/test-designで実テストへ割り当てる。本資料の検査成功はこの製品受入の成功ではない。

## 7. 有効化の順序
canary/rcでA/B検証後stable channelへ。R03の設計・実装は本作業と並行可。ただしR03をstable配布する前にこの更新基盤を受入する。

## 8. 移行失敗とrollback
runtimeは旧sealed generationへ。新stateが旧runtimeで読めない場合はwriteを止め互換移行を行う。更新後の新イベントをsnapshot restoreで捨てない。

## 9. 旧経路をいつ止めるか
advisory CLIは互換wrapperとして残してもよい。無署名/未検証取得を主更新経路として残さない。

## 10. 要求/証拠の対応
この版で一式受入を目指す既存FR：既存FRの追加運用・ライセンス境界を担当。
この版で先行sliceを始めるFR：既に開始した共通契約を継承。
開始と一式受入が別版のFRは、trace/REQUIREMENT_COVERAGE.mdの注記を参照。既存BR/FR/ACのIDとsourceは保持し、新しい架空のPASSを付けない。
