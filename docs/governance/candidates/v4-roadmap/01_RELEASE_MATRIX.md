## 読み方
一つのRは巨大PRではなく複数SLの受入単位。開発の並行性はexecution/01、旧→新切替はmigration/00を参照。0系normal releaseは対象機能の運用受入を満たすが、public API全体の安定は1.0.0で定義。概念v4を採択しても未実装機能が有効になったことにはしない。
