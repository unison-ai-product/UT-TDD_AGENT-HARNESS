# 計画書v2.0の変更

前版v1.3は方針・M0〜M6中心だった。本版はその採択方向を維持し、配布版別の対応範囲、旧新入替、移行/切戻し、HARD依存、作業パッケージ、受入へ再構成した。

- 作業順序予測をRM-ADD-12/SCHED-01〜14へ具体化。R03契約、R04予測、R05配布、R09校正を分離。
- RM-ADD-13として版別capability、writer移行、互換/退役/更新の運用を追加。
- 初回Canary後のMPLをR01（canary.2案）、運用stableをR02（0.2.0案）、構想v4統合をR10（package1.0.0案）へ割当。
- M0〜M6を削除せず版に対応。旧新20領域の準備/既定/旧writer停止/退役時期を記録。
- 元FR59/BR32/AC72と追加13要求を個別対応。候補/実装/実測/受入を混同しない。
- R02/R03の並行開発、R05→BugBotのHARD条件、R07/R08/R09の先行契約を明示。
- 保存形式と分散排他、root parent、lease種別、view改変、refactor不要判定など16論点に推奨と決定期限を設定。
- file分割だけで同じ長文を複製せず、構造化計画catalogから表と版別ページを生成。必要な版/SLだけをAIへ渡せるようにした。

今回の変更は納品資料だけ。GitHub PR/Issue/PLAN/LICENSE/CIへのwrite、実装・runtime試験・正規receipt発行は行っていない。
